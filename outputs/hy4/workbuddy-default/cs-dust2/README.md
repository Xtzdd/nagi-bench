# CS Dust2 5v5

用 React + TypeScript + three.js 从零手写的 3D 第一人称射击原型，复刻 Dust2 核心区域的 5v5 对战。
不使用任何外部资产文件：地图、角色、武器全部在代码里用几何体程序化生成，声音用 Web Audio 程序化合成。
第三方库只有 three / react / react-dom。

## 运行

```bash
npm install
npm run dev      # 打开后点击「点击进入」锁定鼠标
npm run build    # tsc --noEmit && vite build
```

## 操作

WASD 移动 · Space 跳跃 · Shift 静步 · 左键开火 · 右键 AWP 开镜 · R 换弹
1 / 2 / 3 切换主武器 / 副武器 / 近战 · E 安放或拆除 C4 · Tab 计分板
阵亡后按 Space 切换并接管存活队友

## 地图建模：可行走单元格网格

地图不是一堆自由摆放的 AABB，而是一张 80 × 80 的可行走单元格网格（1 格 = 1 米）。这一个决定同时解决了三件事：

- **碰撞**：移动是逐轴、按格做的扫掠，`collides()` 采样玩家半径覆盖的格子 —— 永远不可能穿墙。
- **AI 寻路**：A\* 直接在可行走格上跑，并做拉绳平滑与卡住检测，因此 bot 不会卡在墙角。
- **视线判定**：`losClear()` 就是一次精确的网格步进（Amanatides & Woo），所以"被墙挡住看不见"是字面意义上成立的，不是近似。

已用洪泛填充验证：**2362 个可行走格 100% 从 T 出生点可达**，全部航点与 A、B 两个炸弹点均可达。

完整包含并按 Dust2 实际走位连通：T 出生点、CT 出生点、A 大、A 点、中门（一个真正的门洞，可穿过）、
猫道、B 洞、B 点，另有底部连接走廊与 CT 下坡。

```
src/game/map.ts     区域定义、箱体、网格、碰撞、视线、合并后的墙体几何
src/game/nav.ts     A* + 拉绳平滑 + 直线可通行走查
```

## 角色

每个人形由**独立的头、躯干、双臂（上臂 + 小臂 + 手）、双腿（大腿 + 小腿 + 脚）**构成，不是胶囊或圆柱。
CT 戴头盔、T 戴头巾，两队一眼可辨；默认持枪姿态，武器随角色朝向与俯仰摆动。

命中判定按 **hitbox 分区**：头 / 胸 / 腹 / 手臂 / 腿，各区倍率不同（腹 1.25、手臂 0.78、腿 0.72），
**爆头为基础伤害的两倍**，有护甲时按武器各自的穿甲比例减伤（护甲先扣，剩余伤害才进血量）。

## 回合与 C4

第一回合是**手枪局**：全员只有默认手枪、没有主武器、没有头盔护甲。之后进入长枪局。

C4 由随机一名 T 携带；持包者阵亡后炸弹掉落，可被其他 T 捡起；在 A 点或 B 点范围内按 E 安放（3 秒），
安放后 40 秒倒计时并滴答报警（越接近越急促）；CT 站在炸弹上按 E 拆除（7 秒）。

- T 胜：清空 CT，或 C4 爆炸
- CT 胜：清空 T（且未下包）、成功拆包，或时间耗尽而炸弹未安放

## AI

场上 10 人：1 名玩家 + 4 名 AI 队友对 5 名 AI 敌人。每个 bot 具备：

- 基于网格 A\* 的自主寻路与巡逻，带卡住检测与强制重规划
- 视野索敌：约 115° 视野锥 + 网格视线遮挡 + 62 米距离上限，丢失目标 2.6 秒后放弃
- 交战行为：距离 > 26 米推进、< 6 米后撤、区间内横向拉枪；瞄准误差收敛后才开火
- 参与 C4 流程：T 持包者前往随机炸弹点安放，CT 在炸弹安放后前往拆除

## 声音

全部由 Web Audio 合成。AK / M4 / AWP / Glock / USP / 沙鹰各有不同的开火配方（高频爆音 + 中频枪身 + 低频尾巴的组合与衰减不同），
另有换弹（两段金属声）、脚步（静步与奔跑音量不同）、AWP 开镜与归位、命中反馈（普通与爆头音色不同）、
击杀提示、C4 安放 / 拆除 / 滴答 / 爆炸、回合胜负提示音。
