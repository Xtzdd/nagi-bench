# 章北海 · 陨石子弹 / Zhang Beihai: Meteorite Bullet

一段用 Three.js 在浏览器里程序化生成的 3D 短片，改编自《三体》中章北海狙杀"老航天"的片段。
总时长 5 分 30 秒（330 秒），在任何叙事取舍下都不超过案例规定的 6 分钟硬上限。

## 运行

```bash
bun install      # 或 npm install
bun run dev      # 本地预览
bun run build    # 类型检查 + 生产构建
```

除 `three` 与构建工具外没有任何第三方运行时依赖；视觉、模型、纹理与特效全部由代码生成，
不使用外部资产或 CDN。

## 结构

```
src/
  film/
    voices.ts      语音 cue 清单（id / kind / speaker / text / delivery / start / end）
    shots.ts       分镜表：时间区间 + 场景 + 摄影机关键帧
    vox.ts         体素几何工具（方块、块状球、星空、面板线、材质调色板）
    characters.ts  方块人角色与程序化姿态（idle / speak / walk / aim / work ...）
    sets.ts        11 个场景：片头、轨道、会议厅、舱室、工位、离站平台、舱外、真空、事后、片尾
    audio.ts       Web Audio 程序化音效与 SFX 时间轴
    engine.ts      渲染器、时钟、摄影机插值、场景调度
  ui/
    Subtitle.tsx   由 cue 清单直接驱动的【说话者】字幕
    Hud.tsx        播放控制、时间轴、音量
  App.tsx          组装
  styles.css
```

## 声音设计

全部由 Web Audio 合成，不引入任何音频文件。遵循声音传播的物理环境：

- **室内枪声**：走卷积混响，早期反射密集（办公室/工位的墙壁反射）。
- **真空**：不直接传播外部声音。开枪只给一记经航天服传导的低频闷震（`thump`），
  命中后用静默 + 结构传导的低频 + 泄压嘶声表现，环境只剩一缕 27 Hz 的次声。

字幕统一为画面底部居中的 `【说话者】文本`，不引入其它样式；所有待配音内容集中在
`src/film/voices.ts` 的 cue 清单里，可按 `id` 逐条接入配音。全片不合成任何人声。
